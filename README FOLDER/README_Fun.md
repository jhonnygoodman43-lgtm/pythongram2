Fitur
1. Kalkulator - Melakukan operasi matematika dasar dan lanjutan
2. Catatan - Menyimpan dan mengelola catatan pribadi
3. Manajemen Kontak - Menyimpan, mencari, dan mengelola kontak

Instalasi

Untuk Linux/Termux

1. Install Python 3 (jika belum terinstall)

   # Untuk Ubuntu/Debian
   sudo apt update
   sudo apt install python3 python3-pip
   
   Untuk Termux
   pkg update
   pkg install python

2. Install library colorama
   pip install colorama --break-system-packages
   
   Atau untuk Termux
   pip install colorama
